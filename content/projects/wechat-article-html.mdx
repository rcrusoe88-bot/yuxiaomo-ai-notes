## 这条 Skill 解决什么

写公众号最耗时的不是内容，而是「把 Markdown / Word 变成公众号认得的排版」。anything-to-html 把这一整段抽成一条可复用的命令行工具。

## 核心能力

- 10 个独立主题，兼容旧参数 `orange`、`blue`、`nature`、`morandi`
- Word 正文、表格、内嵌图片按文档顺序提取
- Markdown 标题、列表、引用、代码、表格与本地图片转换
- 正文图片与二维码自动转 base64
- 默认把 `Caveat Bold` 与 `XuanZongTi` 按文章字符子集化并内嵌，无网络依赖
- `--wechat` 生成严格全内联、无 `<style>`、无 `font-family` 的公众号原生字体版本
- 转换完成后自动执行 HTML 与主题契约校验

## 输入 → 输出

```bash
python scripts/convert.py article.md --theme magazine --output article.html
python scripts/convert.py article.md --theme magazine --output article.wechat.html --wechat
```
