# Contributing

Thank you for improving this project.

## Before opening an issue

Search existing issues first. For a bug report, include the expected and actual behavior, a minimal reproduction, and the environment in which it occurred.

## Pull requests

- Keep each pull request focused on one change.
- Explain the problem, approach, and validation performed.
- Do not commit credentials, personal data, or proprietary source material.
- Update documentation when behavior or installation changes.

By contributing, you agree that your contribution may be distributed under this repository's license.
